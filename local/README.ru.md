# Локальный импорт AWG

**Языки:** [English](README.md) · Русский (этот файл)

Обзор репозитория: [README.md](../README.md) · [README.ru.md](../README.ru.md).

Сюда положите **декодированный** конфиг WireGuard/Amnezia в виде обычного `.conf` (секции `[Interface]` / `[Peer]`), в файле **`awg.conf`** — такой путь по умолчанию ожидают `setup-amnezia-full.sh` и `setup-openwrt-awg-pbr.sh` (переменная `CONF_LOCAL`).

Имя и расположение можно изменить: `CONF_LOCAL=/путь/к/вашему.conf ./setup-amnezia-full.sh`.

Если импорт у вас уже был под **другим именем или в другом каталоге**, достаточно скопировать его в `local/awg.conf` или каждый раз передавать `CONF_LOCAL`.

На роутере при полном деплое файл копируется во временный путь **`/tmp/awg-setup.conf`**; для `setup-router-remote.sh` заранее положите конфиг туда.

**Дополнительно (только локально):** экспорты клиента Amnezia (`vpn://…`) можно хранить рядом, например в **`client-vpn-export.conf`** — скрипты деплоя роутера их не читают, это просто удобное место вне git.
