# `amnezia_sites_ru_geoip.json`

**Языки:** [English](amnezia_sites_ru_geoip.md) · Русский (этот файл)

## Что это

- **Большой JSON-снимок** IPv4-префиксов (CIDR) для экспериментов с маршрутизацией вида «российские назначения → WAN, остальное → VPN».
- **Формат:** массив объектов `{ "hostname": "<строка>", "ip": "<строка>" }`. В этом снимке часто в обоих полях записан **один и тот же CIDR** (выгрузка трактовала префикс и как «имя», и как «адрес»).
- **Скрипты из этого репозитория файл не используют** — на роутере список РФ подтягивается с **[ipdeny `ru.zone`](https://www.ipdeny.com/ipblocks/data/countries/ru.zone)** (проще обновлять, меньше объём).

## Источник данных

Набор CIDR соответствует **[ipdeny — Russia IPv4 (`ru.zone`)](https://www.ipdeny.com/ipblocks/data/countries/ru.zone)**. JSON в репозитории — **конвертированный снимок** этого файла: каждая непустая строка-CIDR превращена в `{ "hostname": "<cidr>", "ip": "<cidr>" }` (одно и то же значение в обоих полях). Имя файла историческое; это **не** экспорт стороннего GeoIP-сервиса.

## Как обновлять

1. **На роутере / в скриптах:** по-прежнему используйте сам **`ru.zone`** (см. `ru-direct.sh`). Обновление — повторный деплой или `/etc/init.d/pbr restart`, чтобы `wget` скачал свежий список.
2. **Чтобы заново собрать этот JSON из `ru.zone` у себя** (тот же формат, что в репо):
   - скачать: `wget -O ru.zone https://www.ipdeny.com/ipblocks/data/countries/ru.zone`;
   - убрать комментарии и пустые строки, на каждую строку-CIDR сформировать объект с одинаковыми `hostname` и `ip` (короткий скрипт на `awk` / `jq` / `python`);
   - проверить: `jq empty amnezia_sites_ru_geoip.json`;
   - заменить `amnezia_sites_ru_geoip.json` в корне и закоммитить, напр. `chore: refresh RU CIDR JSON from ipdeny ru.zone`.
