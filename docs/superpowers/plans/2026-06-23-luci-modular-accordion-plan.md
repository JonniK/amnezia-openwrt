# LuCI Modular Accordion UI — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Split the 2302-line `luci-app-amnezia` view into 6 focused LuCI resource modules and present its 13 sections as a two-level native-`<details>` accordion (status open, actions collapsed), with zero behavior change.

**Architecture:** A slim `view/main.js` shell `'require's` 5 section modules + `util.js` under `resources/amnezia/`, spreads each module's `handlers` map onto `view.extend`, composes the accordion from each `module.render(view,data)`, and delegates polling to `Promise.all(module.refresh(view))`. Native `<details>` makes open/closed browser-owned (poll-safe).

**Tech Stack:** LuCI client JS (`baseclass.extend`, `'require'` module system, `E()`/`ui`/`fs`/`poll`), POSIX-sh delivery scripts, bats + `node --check` tests.

## Global Constraints

- **Pure refactor — NO behavior change.** Every moved function body is relocated **verbatim**; only its file location and (for cross-cutting helpers) `util.`-prefixed call sites change. Same RPC calls, same handler names, same UCI/ACL.
- **Never blank the panel.** A bad `require`/syntax error kills the whole view. Every module `node --check` clean; require-graph test proves each required file exists in BOTH `openwrt/` and synced `packages/`.
- **Modules live at `/www/luci-static/resources/amnezia/`** (sibling of `view/`), source `openwrt/luci-app-amnezia/amnezia/`. Require paths: `amnezia.util`, `amnezia.section.{failover,routing,zapret,dns,autolearn}`.
- **The `#failover-tunnel-table` id must remain** in `failover.render` output (poll self-unregister sentinel).
- **The full bats suite + `node --check` + sync-parity stay green after EVERY phase.** Negative `! grep` guards run over `ALLJS` (union of all shipped JS), paired with positive anchors.
- Source of truth is `openwrt/`; `packages/` is generated by `dev/sync-to-packages.sh` only — never hand-edit `packages/`.
- Commit after every phase (git is the review handoff). Deploy to the live router is **out of scope / user-gated**.

### Module boilerplate template (every section module)

```js
'use strict';
'require baseclass';
'require fs';            // only cores actually used by this module
'require ui';
'require amnezia.util';  // if it calls fmtDur/fmtAge/verdictColor/uiConfirm

// ---- file-scope private state (moved verbatim from main.js) ----
var someInFlight = false;
function parseX(text) { /* moved verbatim */ }
function paintX(s)    { /* moved verbatim */ }

return baseclass.extend({
  handlers: {
    handleX: function(ev) { /* moved verbatim; `this` === view */ },
  },
  render: function(view, data) {
    // build this family's accordion panel; use ui.createHandlerFn(view,'handleX')
    // do the FIRST paint inline from `data`
    return E('details', { 'class': 'amnezia-panel', 'open': '' }, [ E('summary', {}, _('…')), /* … */ ]);
  },
  refresh: function(view) {
    return Promise.all([ /* this family's fs reads/execs → paint by id */ ]);
  }
});
```

`util.js` is the same shape minus `handlers`/`render`/`refresh`: `return baseclass.extend({ fmtDur:…, fmtUptime:…, fmtAge:…, verdictColor:…, uiConfirm:… });` and `'require ui';` (uiConfirm builds a modal).
